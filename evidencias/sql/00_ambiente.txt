Como a instância vazia foi criada
  O servidor do XAMPP da porta 3306 não foi usado. Foi criada uma instância
  separada e vazia, numa pasta temporária, só para este teste:

  1. Criar o diretório de dados vazio:
     C:\xampp\mysql\bin\mysql_install_db.exe --datadir=<pasta temporária>\data --port=3307

  2. Iniciar o servidor em segundo plano, sem ler o my.ini do XAMPP:
     C:\xampp\mysql\bin\mysqld.exe --no-defaults --basedir=C:/xampp/mysql
       --datadir=<pasta temporária>/data --port=3307 --bind-address=127.0.0.1
       --sql-mode=NO_ZERO_IN_DATE,NO_ZERO_DATE,NO_ENGINE_SUBSTITUTION
       --character-set-server=utf8mb4 --collation-server=utf8mb4_general_ci

  3. Antes de rodar os scripts, a instância só tinha os bancos do sistema:
     information_schema, mysql, performance_schema e test.

  4. Conexão usada em todos os scripts (usuário root sem senha, só local):
     mysql.exe -u root -P 3307 --protocol=TCP -h 127.0.0.1 -t --default-character-set=utf8mb4

  5. No final, a instância foi desligada com
     mysqladmin.exe -u root -P 3307 --protocol=TCP shutdown
     e a pasta temporária de dados foi apagada.
